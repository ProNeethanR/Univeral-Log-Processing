## Purpose

`syslog-demo-001` exists specifically to demonstrate the complete ULPF pipeline when all required
source context is explicitly known by the project/data owner. It proves:

- Syslog format detection
- Deterministic RFC3164 parsing
- Source Profile registration, persistence, and activation
- Authoritative source-context injection (year, timezone, vendor, product)
- Deterministic timestamp normalization from yearless RFC3164 timestamps
- Vendor/product enrichment from registered Source Profile
- OCSF 1.3.0 Network Activity event production
- OCSF validation: **PASS** (all required fields present)
- Raw-byte lossless preservation
- SHA-256 integrity verification
- Historical replay after profile deactivation
- vault `profile_version` metadata persistence
